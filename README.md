# Igna Djongo

L'application de l'Igna Djongo : membres, cotisations, caisse et histoire.

Conçue par **M.M.B.T** (2026). Tous droits réservés, voir [LICENCE](LICENCE).

Ouvrir : https://kalmache.github.io/igna-djongo/

Ce dépôt contient la version publiée. Elle est construite à partir de `app/index.html`
avec `site/build.py` dans les fichiers du projet Claude.

## Appli Android (APK)

Télécharger : https://kalmache.github.io/igna-djongo/igna-djongo.apk

L'APK est une petite coquille qui affiche le site en ligne : les mises à jour du site
arrivent sans réinstaller. Source dans `source/android/`, construction avec
`source/android/build-apk.sh` (outils pris sur Maven Central). La clé de signature
n'est pas dans ce dépôt : elle reste dans les fichiers privés du projet.
